# MATS Nepal — Website

Premium travel website for MATS Nepal (Maitri Apartment and Travel Services Pvt. Ltd.)

## Pages
- `index.html` — Homepage
- `flights.html` — Flight booking
- `bus.html` — Transport booking
- `stays.html` — Accommodation listings
- `tours.html` — Tour packages
- `privacy.html` — Privacy policy

## Assets
- `css/style.css` — All styles
- `js/main.js` — All JavaScript

## Setup
Open `index.html` in any modern browser. No build step required.
All images load from Unsplash CDN. Internet connection required for fonts and images.
